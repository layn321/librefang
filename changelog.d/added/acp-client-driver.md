New `claude-code-acp` and `codex-acp` providers drive Claude Code and Codex as Agent Client Protocol agents through their ACP adapters, so LibreFang streams a real CLI session instead of a print-mode subprocess. The adapter gets an allowlisted environment and a per-turn scratch working directory by default. Permission requests the adapter sends are answered by a configurable policy that denies by default and logs every decision; for Claude the driver also turns bypass off for the session and enforces the `default` permission mode, but allow rules in the user's own Claude settings still apply before any request is sent.
